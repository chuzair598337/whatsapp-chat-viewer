# To do

Work the maintainer has asked for that isn't built yet.

How this list works:
- **Only on the maintainer's request.** An item goes here when the maintainer asks for it, or when the maintainer approves something a contributor or coding agent noticed. Ideas nobody has approved stay out of this file.
- **One line per item**, saying what is wanted, with the date it was asked for and who noticed it (the maintainer or an agent).
- **When an item is built and tested,** remove it from this list and describe the result in [features.md](features.md). Note it in [CHANGELOG.md](../CHANGELOG.md) too. Don't tick items off and leave them here.
- **Out of scope:** ideas that were ruled out live in [deferred.md](deferred.md), not here.

Each item is tested with both a `.zip` export with media and a `.txt` export without media before it moves to the features page (see [PROJECT_RULES.md](../PROJECT_RULES.md), section 2).
